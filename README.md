#  Mobile Sales Dashboard

An interactive business intelligence dashboard that visualizes mobile phone sales across cities, models, payment methods, and time periods. Built to empower strategic decisions through clear insights into sales performance, customer behavior, and transaction trends.

##  Project Overview

This dashboard provides a comprehensive view of mobile sales data, enabling stakeholders to:

- Monitor month-to-date (MTD) performance
- Compare sales across cities and mobile models
- Analyze customer ratings and payment preferences
- Track trends across months, quarters, and years

## 📊 Key Features

- **MTD Metrics**: Total Sales, Quantity, Transactions, Average Price
- **Filters**: Mobile Model, Payment Method, Brand, Year
- **Visualizations**:
  - 📍 Map: City-wise sales and transactions
  - 📈 Line Chart: Monthly quantity trends
  - 📊 Bar Charts: Sales by model, day, rating status
  - 🥧 Pie Chart: Payment method distribution
  - 📅 Time Comparison: Year-over-year and quarter-over-quarter metrics

The dataset includes:
- Mobile sales transactions

All data is anonymized and used for educational and portfolio purposes.
